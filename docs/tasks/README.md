# Tasks

This folder tracks actionable work.

## Conventions
- Prefer many small tasks over one giant checklist.
- Use checkboxes for status.
- Link to relevant files/paths and acceptance criteria.

## Suggested files
- `backlog.md` — long list of ideas
- `now.md` — current sprint/next 1–2 weeks
- `bugs.md` — known bugs and repro steps
- `performance.md` — perf issues, metrics, suspected hotspots
